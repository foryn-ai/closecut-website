# Component Strategy

Verified imports only.

## Rules
1. Aceternity components live in `src/components/aceternity/`.
2. Each component must have a matching playground page before it is used in real pages.
3. If a component does not match the demo, use a stub that keeps the same API and layout.
4. Replace stubs only after the playground view matches expected behavior.
5. Editorial pages should use `Section` and `SurfaceCard` for rhythm and soft surfaces without heavy borders.
